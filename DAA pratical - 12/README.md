The Travelling Salesman Problem (TSP) is an optimization problem that aims to find the shortest possible route for visiting every city exactly once and returning to the starting city. In this Python program, the brute-force approach is used to generate all possible routes and calculate their total distances. The route with the minimum distance is selected as the optimal solution.
